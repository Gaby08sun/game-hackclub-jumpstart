A minimalist 2D precision platformer built with Godot for Hack Club Haven.
​Navigate through 5 single-screen rooms, dodge hazards, and reach the door with the lowest death count possible.


​Play directly in your browser:
https://gaby008.itch.io/jumpstart


​Controls

​Move Left / Right: A / D or Left / Right Arrow
​Jump: Space / Up Arrow
​Quick Restart: R



​Features

​5 Single-Screen Levels
​Death Counter
​Instant Respawn
